# コマ割りフォルダ 使用方法ガイド (Panel Folder Guide)

『PaintSoft KABURAGI』の**コマ割りフォルダ**機能は、マンガやイラスト制作においてコマ枠の作成・分割・変形・枠内マスク（クリッピング）を直感的に行える機能です。
CLIP STUDIO PAINTのコマ枠フォルダーに近い設計となっており、コマ枠ごとに独立したレイヤー管理と作画が可能です。

## 1. コマ割りフォルダの概要と特徴

- **自動枠外クリッピング（マスク）**  
  コマ割りフォルダ内のレイヤーに描いた線画や塗りは、**コマ枠の内側だけに自動的に制限**されます。枠線の外にはみ出した描画は自動的に隠れるため、枠外を消しゴムで消す手間が不要です。
- **自動枠線レンダリング**  
  コマ枠の境界線（外枠線）はベクターポリゴンとして管理され、指定した線幅・色で常に滑らかに描画されます。
- **コマ単位のレイヤー管理**  
  1つのコマにつき1つの「コマ割りフォルダ」が作られるため、レイヤーパネルでコマごとの整理や並べ替え、非表示切り替えが容易です。

```
[レイヤー構造の例]
▼ コマ 1 (コマ割りフォルダ)  ← この枠内にクリッピングされる
  ├─ 線画
  ├─ 着彩 / トーン
  └─ 背景
▼ コマ 2 (コマ割りフォルダ)
  ├─ キャラ
  └─ 背景
```

## 2. コマ枠の作成方法

コマ枠を作成するには、以下の2つの方法があります。

### 方法A: メニューバーから原稿全体の基本枠を作成
1. 上部メニューの **[レイヤー]** → **[新規コマ割りフォルダ]** を選択します。
2. キャンバスの内枠マージンに合わせた基本コマ枠フォルダが自動作成され、フォルダ内に作画用の新規通常レイヤーが1枚配置されます。
3. この基本枠を後述の「コマ割ツール」で割っていくのがマンガ制作の標準的な流れです。

### 方法B: コマ枠ツールで自由な位置に作成
1. ツールボックスから **[コマ枠]** ツールを選択します。
2. キャンバス上を左クリックしながら対角線上にドラッグします。
3. ドラッグした矩形の範囲に新しいコマ割りフォルダが作成されます。

## 3. コマ枠の分割（コマ割り）

作成したコマ枠を縦・横・斜めにカットして複数のコマに分割します。

1. ツールボックスから **[コマ割]** ツールを選択します。
2. コマ枠設定パネルで「**左右間隔**」「**上下間隔**」を確認・調整します。
3. 分割したいコマ枠を横切るようにマウスをドラッグして線を引きます。
   - **水平分割（段割り）**: 左右方向に水平にドラッグします。上下に2分割されます。
   - **垂直分割**: 上下方向に垂直にドラッグします。左右に2分割されます。
   - **斜め分割**: 斜めにドラッグします。斜めのカットラインで分割され、動きのあるアクションコマや変形コマが作成できます。
4. ドラッグを離すと、指定した間隔（マージン）の隙間を空けて元のコマが2つの独立したコマ割りフォルダに自動分割されます。

> [!TIP]
> 日本の漫画表現では、**段の間隔（上下間隔）を広め（例: 35〜45px）**、**同じ段のコマ間（左右間隔）を狭め（例: 15〜20px）** に設定すると、読者の視線が自然に右上→左→一段下へと誘導されます。

## 4. コマ枠の形状変形・調整

コマ枠のサイズ変更や斜めゴマへの変形は、キャンバス上で直接行えます。

1. **[コマ枠]** または **[コマ割]** ツールを選択します（または編集したいコマ割りフォルダをレイヤーパネルでアクティブにします）。
2. キャンバス上のコマ枠にマウスカーソルを合わせると、枠線上に**頂点ハンドル（四隅の点）**と**辺ハンドル（四辺）**が表示されます。
   - **角の頂点（Vertex）をドラッグ**:  
     頂点を自由に移動させることができ、三角形や台形、平行四辺形などの変形コマを直感的に作成できます。
   - **辺（Edge）をドラッグ**:  
     辺全体を平行にスライドさせてコマの幅や高さを伸縮・拡大できます。
   - **スナップ機能**:  
     設定パネルで「裁ち落とし線にスナップ」が有効な場合、原稿の仕上がり枠やトンボに自動吸着します。

## 5. コマ枠設定（ツールプロパティ）の項目

コマ枠・コマ割ツール選択時に表示される設定パネル（PanelSettingsWidget）の各項目です。

| 設定項目 | 内容 | 初期値 |
| :--- | :--- | :--- |
| **枠線を描画する** | チェックを外すと、枠線の黒線を描画せずクリッピングマスクのみ機能します（回想コマや背景タチキリ用）。 | オン (有効) |
| **線の太さ (px)** | コマ枠線の太さをピクセル単位で指定します。 | `3.0 px` |
| **枠線の色** | カラーピッカーボタンから枠線の色を変更できます。 | 黒 (`#000000`) |
| **左右間隔 (px)** | コマ割ツールで垂直（左右）に分割した際のコマとコマの隙間の幅です。 | `20.0 px` |
| **上下間隔 (px)** | コマ割ツールで水平（上下）に分割した際の段と段の隙間の幅です。 | `40.0 px` |
| **裁ち落とし線にスナップ** | コマ枠作成・変形時に原稿の仕上がり線（タチキリ線）に吸着させます。 | オン (有効) |

## 6. コマ枠内での作画・レイヤー操作

1. **枠内での作画**:
   - レイヤーパネルで対象のコマ割りフォルダ内のレイヤーを選択し、ペンやブラシ、バケツツール等で作画します。
   - 枠外にはみ出して描いた線や塗りは自動的にマスクされるため、はみ出しを気にせず勢いのあるストロークで描画できます。
2. **フォルダ内へのレイヤー追加**:
   - コマ割りフォルダが選択された状態で新規レイヤーを作成すると、そのコマフォルダの子レイヤーとして追加されます。
   - 線画レイヤー、着彩レイヤー、トーンレイヤー、下描きレイヤーなどを自由に重ねることができます。

## 7. 便利なテクニック・応用

### コマ枠からキャラクターやフキダシを飛び出させたい場合
- コマ枠からはみ出してキャラクターの手足や武器、フキダシ（テキスト吹き出し）、効果線などを描きたい場合は、**対象のレイヤーを「コマ割りフォルダの外側（上の階層）」に配置**します。
- コマ割りフォルダの外にあるレイヤーには枠外マスクがかからないため、コマ枠線をまたいで画面いっぱいに飛び出すダイナミックな演出が可能です。

### タチキリ（裁ち落とし）コマの作り方
- 見開きや大ゴマなどでページの端まで絵を広げたい場合、辺ハンドルまたは頂点ハンドルをドラッグしてキャンバスの端（裁ち落とし領域）まで枠を広げます。
- 枠線が不要な外周部分は、設定パネルの「枠線を描画する」をオフにするか、キャンバスの外側に枠線を追い出すことで綺麗なタチキリが作成できます。
