# コマ割りフォルダ 使用方法ガイド (Panel Folder Guide)

『PaintSoft KABURAGI』の**コマ割りフォルダ**機能は、マンガやWebtoon、イラスト制作においてコマ枠の作成・テンプレート配置・分割・結合・連動変形・枠内マスク（自動クリッピング）を直感的に行える高機能ツールです。
CLIP STUDIO PAINTのコマ枠フォルダーに近い設計となっており、コマ枠ごとに独立したレイヤー管理と自由な作画が可能です。

## 1. コマ割りフォルダの概要と特徴

- **自動枠外クリッピング（マスク）**  
  コマ割りフォルダ内のレイヤーに描いた線画や塗りは、**コマ枠の内側だけに自動的に制限**されます。枠線の外側へのはみ出しは自動的にマスクされるため、消しゴムで枠外を消す手間が不要です。
- **ベクター外枠線の自動レンダリング**  
  コマ枠の輪郭（外枠線）はベクターポリゴンとして保持され、指定した太さ・色で常にジャギーのない滑らかな線として描画されます。
- **コマ単位のレイヤー管理**  
  1つのコマにつき1つの「コマ割りフォルダ（GroupLayer）」が生成され、フォルダ内に線画、着彩、背景レイヤーをまとめて格納できます。
- **完全な Undo / Redo 対応**  
  新規作成、分割、結合、頂点変形など、すべての操作が「元に戻す（Ctrl+Z）」「やり直し（Ctrl+Y / Ctrl+Shift+Z）」に対応しています。

```
[レイヤー構造の例]
▼ [▼ グループ] コマ 1 (コマフォルダ)  ← この枠内に自動マスク
  ├─ [通常] 線画
  ├─ [通常] 着彩 / トーン
  └─ [通常] 背景
▼ [▼ グループ] コマ 2 (コマフォルダ)
  ├─ [通常] キャラ
  └─ [通常] 効果線
```

## 2. 新規コマフォルダの作成（テンプレート／グリッド指定）

上部メニューの **[レイヤー]** → **[新規コマフォルダ]** を選択するか、レイヤーパネルの **[コマフォルダ]** ボタンをクリックすると、**新規コマフォルダ作成ダイアログ**が表示されます。

### ① テンプレートから選択
用途に応じた多数のレイアウトテンプレートが用意されています：
- **四コマ漫画 (1列 × 4コマ)**: スタンダードな4コマレイアウト
- **四コマ漫画 (タイトル枠あり)**: 最上段にタイトル用コマを設けた4コマ（計5コマ）
- **四コマ漫画 2本 (2列 × 4コマ)**: 見開きや横並びの2本立て（計8コマ）
- **四コマ漫画 2本 (タイトル枠あり)**: 左右両方にタイトル枠が付いた2本立て（計10コマ）
- **3段均等 (1列 × 3コマ)** / **2段均等 (1列 × 2コマ)**
- **各種ストーリーマンガ変則レイアウト**（大ゴマ強調、アクション向け変形など）
- **1コマ全体**: キャンバス内枠いっぱいの単一コマ

### ② コマ数・グリッド指定モード
- 「横のコマ数（列数）」「縦のコマ数（行数）」をユーザーが自由に数値入力して等分割生成できます（例: 1×1, 1×2, 2×3, 3×4など）。

### ③ 余白・間隔・枠線設定とプレビュー
- **左右余白 / 上下余白**: キャンバス外周からコマ枠までのマージンを指定。
- **左右コマ間隔 / 上下コマ間隔**: コマとコマの間の隙間幅を指定。
- **枠線の太さ / 枠線の色**: 初期枠線の太さ（px）と色を指定。
- **リアルタイムプレビュー**: 設定を変更すると右側のプレビュー画面にリアルタイムで反映されます。

> [!NOTE]
> **ダイアログ設定の自動記憶**:  
> ダイアログで設定したモード、選択テンプレート、コマ数、マージン、枠線幅・色などの設定内容は自動的に記憶され、次回ダイアログ表示時や次回アプリケーション起動時にも前回の設定が自動復元されます。

### 手動での作成（コマ枠ツール）
1. ツールボックスから **[コマ枠]** ツールを選択します。
2. キャンバス上を左クリックしながら対角線上にドラッグします。
3. ドラッグした矩形の範囲に新しいコマ割りフォルダが作成されます。

## 3. コマ枠の分割（コマ割り）

コマ枠を分割するには、**「ドラッグによる分割（コマ割ツール）」** と **「等分割ダイアログ」** の2種類の方法があります。

### 方法A: コマ割ツールによるドラッグカット
1. ツールボックスから **[コマ割]** ツールを選択します。
2. コマ枠設定パネルで「左右間隔」「上下間隔」を確認・調整します。
3. 分割したいコマ枠を横切るようにマウスでドラッグして直線を引きます。
   - **水平ドラッグ**: 上下に2分割（段割り）。段間隔（上下間隔）が適用されます。
   - **垂直ドラッグ**: 左右に2分割。コマ間隔（左右間隔）が適用されます。
   - **斜めドラッグ**: 斜めにカットされ、アクションシーンなどの変形コマを作成できます。
4. ドラッグを離すと、指定した隙間を空けて元のコマが2つの独立したコマフォルダに分割されます。

### 方法B: コマの等分割ダイアログ
1. 編集対象のコマ割りフォルダを選択した状態で、コマ枠設定パネルの **[コマを等分割...]** ボタンをクリック（またはメニュー操作）します。
2. **分割ダイアログ**が開きます：
   - **分割方向**: 「垂直に分割（左右に分割）」または「水平に分割（上下に分割）」を選択。
   - **分割数**: 2 〜 10 等分から指定。
   - **コマ間隔 (px)**: 分割間の隙間幅を指定。
3. **[OK]** を押すと、対象のコマ枠が正確に均等分割され、分割後の各コマフォルダおよび作画レイヤーが自動生成されます。

## 4. 隣接するコマ枠の結合

隣り合う2つのコマ枠を1つのコマ枠にマージ（一体化）できます。

1. レイヤーパネルで結合元のコマ割りフォルダを選択します。
2. コマ枠設定パネルの **[隣接するコマと結合...]** ボタンをクリックします。
3. **コマ結合ダイアログ**が表示され、選択中コマの上・下・左・右に隣接しているコマ枠が自動検出されて候補一覧に表示されます。
4. 結合相手のコマを選択して **[OK]** を押します。
5. 2つのコマ枠ポリゴンが一体化（コマ間の隙間も綺麗に埋められます）され、双方のコマ内にあった作画レイヤーが1つのコマフォルダ内にまとめられます。

## 5. コマ枠の形状変形と「隣接コマと連動」

コマ枠の四隅の頂点や辺をドラッグして、コマサイズや形状を自由に変形できます。

1. **[コマ枠]** または **[コマ割]** ツールを選択し、変形したいコマ枠フォルダをアクティブにします。
2. キャンバス上のコマ枠にカーソルを合わせると、**頂点ハンドル（四隅の点）** と **辺ハンドル（四辺）** がハイライト表示されます。
   - **頂点（Vertex）をドラッグ**:  
     頂点を自由に移動させることができ、三角形や台形、平行四辺形などの変形コマを作成できます。
   - **辺（Edge）をドラッグ**:  
     辺全体を平行移動させてコマの幅や高さを拡大・縮小できます。

### 「隣接コマと連動」オプション
コマ枠設定パネルにある **「隣接コマと連動」** チェックボックスをオンにすると、マンガ制作に非常に便利な連動変形が行えます：
- あるコマの頂点や辺を移動した際、**境界を接している隣接コマの対応する頂点・辺も、コマ間隔（マージン）を維持したまま一緒に追従して移動**します。
- 例えば、コマ1の右下頂点を左に動かすと、右隣のコマ2の左下頂点や下のコマ3の右上頂点も自動的に間隔を保って連動するため、ページ全体のコマ枠の整合性を崩さずにレイアウト調整が可能です。
- 連動させずに単独のコマだけを独立して変形したい場合は、チェックをオフにします。

## 6. コマ枠設定（ツールプロパティ）の全項目一覧

コマ枠・コマ割ツール選択時にサイドバーの設定パネル（PanelSettingsWidget）に表示される項目です。

| 設定項目 | 説明 | 初期値 |
| :--- | :--- | :--- |
| **枠線を描画する** | チェックを外すと、枠線の黒線を描画せずクリッピングマスクのみ機能します（回想シーンやタチキリ用）。 | オン (有効) |
| **線の太さ (px)** | コマ外枠線の太さをピクセル単位で指定します（0.5〜50.0 px）。 | `3.0 px` |
| **枠線の色** | カラーボタンをクリックして枠線の色を自由に変更できます。 | 黒 (`#000000`) |
| **左右間隔 (px)** | コマ割ツールで垂直分割した際、および等分割時のコマ間の隙間幅です。 | `20.0 px` |
| **上下間隔 (px)** | コマ割ツールで水平分割した際、および等分割時の段間の隙間幅です。 | `40.0 px` |
| **隣接コマと連動** | 頂点や辺の移動時、隣接するコマ枠も間隔を保ったまま連動して変形します。 | オン (有効) |
| **裁ち落とし線にスナップ** | キャンバスの仕上がり線（タチキリ枠）付近に頂点や辺を自動吸着させます。 | オン (有効) |
| **[隣接するコマと結合...]** | 隣接するコマを選択して1つのコマ枠に統合するダイアログを開きます。 | ボタン |
| **[コマを等分割...]** | 選択中のコマ枠を縦・横に均等分割するダイアログを開きます。 | ボタン |

## 7. レイヤービューでの管理・グループの展開と格納

### グループの展開／格納（折りたたみ）
- レイヤーパネル内のコマフォルダには `[▼ グループ]` または `[▶ グループ]` と表示されます。
- **`[▼ グループ]` の文字部分をクリック**すると、フォルダが格納（折りたたみ）され、コマ内の子レイヤーが非表示に畳まれます。
- **`[▶ グループ]` を再度クリック**すると展開され、子レイヤーの一覧が再表示されます。
- コマ数が多いページでも、レイヤーリストをすっきり整理して目的のコマへ素早くアクセスできます。

### 枠外マスクと作画
- コマフォルダ内のレイヤーに描いた内容は、コマ枠の外周ポリゴンによって自動的にマスクされます。
- コマ枠の形状を変形すると、マスク領域もリアルタイムに追従して更新されます。

## 8. 便利なテクニック・応用

### コマ枠からキャラクターやフキダシを飛び出させたい場合
- コマ枠線をまたいでキャラクターの手足、武器、フキダシ（テキスト吹き出し）、効果線などを描きたい場合は、**対象のレイヤーを「コマ割りフォルダの外側（上の階層）」に配置**します。
- コマフォルダの外側にあるレイヤーにはコマ枠マスクがかからないため、画面いっぱいに飛び出すダイナミックな演出が可能です。

### タイトル枠付き四コマ漫画の作成
- 新規コマフォルダ作成ダイアログで **「四コマ漫画 (タイトル枠あり)」** を選ぶと、第1コマの上に薄いタイトル専用のコマ枠が自動配置されます。
- タイトル枠内にテキストツールで作品タイトルを入れ、下の4コマで作画を行うだけで、整然とした4コマ漫画の原稿が即座にセットアップできます。

### タチキリ（裁ち落とし）コマの作り方
- ページの端まで絵を広げたい場合、辺ハンドルまたは頂点をドラッグしてキャンバスの端（裁ち落とし領域）まで枠を広げます。
- 外周枠線が不要な場合は、設定パネルの「枠線を描画する」をオフにするか、キャンバス外まで枠線を広げることで綺麗なタチキリが作成できます。
